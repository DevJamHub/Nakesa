# Exercise Week — Peta Pekerjaan per Pertemuan

Pekerjaan NAKESA disusun mengikuti pertemuan kuliah **Pemrograman Web**. File aplikasi tetap di tempatnya (`html/`, `js/`, `css/`) supaya aplikasi tetap berjalan; folder `week-N` di sini menunjukkan **apa yang dikerjakan di setiap week, file mana, dan oleh siapa**, sesuai riwayat git asli.

Week berikutnya ditambahkan setiap pertemuan selesai: milestone `Week N`, label `week-N`, issue tugas `[Week N] …` dengan sub-issue `[Week N · Task 0X] …`, folder `week-N/`, dan tag `week-N`.

## Struktur pengerjaan

| Bagian | Isi | Tempat |
|---|---|---|
| **A. Tugas Matkul** | Week → Task 01, 02, … sesuai slide | tabel di atas, milestone `Week N`, label `task` |
| **B. Fitur Tambahan** | Fitur aplikasi di luar task yang diminta | tabel di bawah, milestone `Fitur Tambahan`, label `epic` |
| **C. Pendukung** | Dokumentasi, testing, alur kerja tim | milestone `Pendukung` |

Daftar isi lengkap semua issue: [📌 Peta Issues #73](https://github.com/DevJamHub/Nakesa/issues/73).
